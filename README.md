# Offline-IW7-Mod

<p align="center">
  <img src="assets/github/banner.png?raw=true" />
</p>

<br>

**REMOVED** Requirement that you must own a steam version of the game in order to run the client. The reason for this is that the original code broke the client on Steam Deck/Linux Operating Systems.
Nonetheless I recommend you purchase the game on Steam when it goes on sale, but it is not required: https://store.steampowered.com/app/292730/Call_of_Duty_Infinite_Warfare/

While I made this fork specifically to make Zombies Offline, Multiplayer with Bots as well as Campaign also works with this mod as well! If you want any parts of the offline experiance of Infinite Warfare, this mod is for you!

I especially wanted to make this fork as the original repository required you to compile everything all by yourself and you can't do that on Linux! For you folks in particular who wanted to play this offline on the Steam Deck, I compiled it so you didn't have to!

## Installation

- Simply go to releases, download the exe and place it into your Infinite Warfare root folder.
- If you are on Windows, just simply run by double-clicking the iw7-mod.exe and it will start the game.
- If you are on Steam Deck/Linux, add the iw7-mod.exe onto steam as a "Non-Steam" Game, go into properties and force steam to choose a specific compatibility layer to the game, choose either Proton Experimental or the latest Proton version and play the game through steam.
- If you want to unlock all of the fortune cards and weapon varients, go to the console my typing "~" and type "cg_unlockall_loot 1", "cg_unlockall_items 1", and "cg_unlockall_classes 1". Make sure to type all of these seperately and press enter after you type each one. This mod **DOES NOT** and **WILL NOT** unlock the Zombies DLC maps, you either will have to purchase them through steam or find them elsewhere.
- If you want to change your name in the game, simply go the console the same way by unlocking all items and type "name **type anything here**".
